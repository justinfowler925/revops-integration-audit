# Diagrams reference

All diagrams in this repository are encoded as Mermaid markdown blocks. GitHub
renders them natively. For embedded use elsewhere:

1. **Screenshot the rendered version on GitHub** (right-click → "Save image as…")
2. **Re-render via mermaid.live** — paste the Mermaid source, export as PNG/SVG
3. **Use mermaid-cli** for programmatic SVG generation

The Mermaid source for each diagram lives inline in the README.md, so
modifications happen there.
